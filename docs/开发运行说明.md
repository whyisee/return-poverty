# 开发运行说明

> 日期：2026-05-13  
> 项目：中年返贫四件套经营模拟器

## 1. 当前进度

当前已经完成第一版 MVP 骨架：

- 前端：React + Vite + Ant Design。
- 后端：Python + FastAPI。
- 数据：第一版使用 seed JSON + 内存存档跑通快速体验闭环。
- 数据库：已在开发设计中定义 MySQL 表结构，部署配置中预留 MySQL 服务，下一阶段接入 SQLAlchemy Repository。

已实现的用户流程：

```text
首页选择角色、赛道、开局包
  -> 创建游戏局
  -> 进入 7 天经营台
  -> 每天选择经营动作
  -> 后端结算账本和风险提示
  -> 生成创业体检报告
```

## 2. 后端启动

推荐使用统一脚本：

```bash
bash scripts/dev.sh setup
bash scripts/dev.sh start
```

查看状态：

```bash
bash scripts/dev.sh status
```

查看日志：

```bash
bash scripts/dev.sh logs
```

停止服务：

```bash
bash scripts/dev.sh stop
```

如果需要手动启动，可以按下面的方式执行。

进入后端目录：

```bash
cd backend
```

创建虚拟环境：

```bash
python3 -m venv .venv
```

安装依赖：

```bash
.venv/bin/pip install -e ".[dev]"
```

启动服务：

```bash
.venv/bin/uvicorn app.main:app --reload --host 127.0.0.1 --port 8101
```

健康检查：

```bash
curl http://127.0.0.1:8101/health
```

接口文档：

```text
http://127.0.0.1:8101/docs
```

## 3. 前端启动

进入前端目录：

```bash
cd frontend
```

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

访问：

```text
http://127.0.0.1:3101
```

前端 Vite 已配置 `/api` 代理到 `http://127.0.0.1:8101`。

## 4. 目录说明

```text
frontend/
  src/pages/          页面
  src/components/     经营台、账本、决策卡等组件
  src/services/       API 请求封装
  src/types/          前后端数据类型
  src/styles/         全局样式

backend/
  app/api/v1/         API 路由
  app/services/       业务服务
  app/engine/         模拟计算引擎
  app/schemas/        Pydantic 数据模型
  app/seed/           第一版内容配置
```
