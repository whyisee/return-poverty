# 中年返贫四件套经营模拟器设计方案

> 版本：v0.1  
> 日期：2026-05-13  
> 项目位置：`money-lab/game-site`  
> 现有基础：小店 7 天经营挑战

## 1. 项目定位

### 1.1 项目名称

推荐主标题：

**中年返贫四件套：小店生死账**

副标题：

**奶茶、汉堡、咖啡、烘焙，四条看起来最容易入局的小店赛道。**

### 1.2 核心体验

用户扮演一名准备靠餐饮小店翻身的中年创业者，在不同资金、家庭压力、城市位置和加盟诱惑下，完成从“想开店”到“筹备、开业、经营、调整、扩张或止损”的完整模拟。

项目不是简单的亏钱段子，也不是纯经营爽游，而是用网络梗做入口，让用户体验真实小店经营里最容易被忽略的东西：

- 现金流比营业额重要。
- 加盟费只是开始，持续成本才是真压力。
- 爆单不等于赚钱，满减、平台抽成、损耗、人工会吞掉利润。
- 中年创业风险不只在店里，也在房贷、孩子、父母、身体和债务里。
- 及时止损不是失败，可能是最理性的高分结局。

### 1.3 双模式设计

项目提供两个入口：

| 模式 | 单局时长 | 目标用户 | 核心价值 |
| --- | --- | --- | --- |
| 快速体验版 | 7-10 分钟 | 第一次访问、社交传播用户 | 快速理解“返贫四件套”的风险结构 |
| 完整流程版 | 30-60 分钟，可分段保存 | 想认真体验经营模拟的用户 | 完整走完开店前、中、后的决策链路 |

现有的“小店 7 天经营挑战”可以改造成快速体验版；完整流程版作为主项目升级方向。

## 2. 现实基调与边界

### 2.1 四件套定义

本项目采用当前网络语境里的餐饮创业版“四件套”：

1. 奶茶
2. 汉堡
3. 咖啡
4. 烘焙

它们共同特征：

- 看起来门槛低。
- 容易被短视频、加盟招商、朋友成功案例影响。
- 前期投入可大可小，但试错成本并不低。
- 赛道高度同质化，价格战和位置竞争明显。
- 用户常误以为“毛利高”等于“净利润高”。

### 2.2 表达原则

- 可以有梗，但不嘲笑中年困境。
- 可以制造压力，但不做恶意羞辱。
- 不把所有失败都归咎于玩家能力，要呈现外部环境的不确定性。
- 不给具体投资建议，不承诺收益。
- 每局结局要强调复盘：错在哪里、什么地方做对了、是否应该止损。

### 2.3 参考现实变量

系统数值不需要精确对应真实门店，但要体现现实经营逻辑：

- 启动资金：加盟费、设备、装修、押金、首批物料。
- 固定成本：房租、人工、贷款、家庭支出。
- 变动成本：原材料、平台抽成、营销、满减、报废。
- 经营风险：天气、竞品、差评、设备故障、员工流失、总部推销。
- 家庭风险：房贷、父母体检、孩子费用、伴侣压力、身体透支。

## 3. 用户画像与剧情入口

### 3.1 玩家角色

完整流程版开局先选“人”，再选“店”。角色会影响初始资金、家庭压力、时间精力和抗风险能力。

| 角色 | 初始状态 | 优势 | 风险 |
| --- | --- | --- | --- |
| 被裁中层 | 有补偿金和管理经验 | 初始资金较高，懂一点数据 | 房贷和家庭支出高，再就业焦虑强 |
| 县城夫妻店 | 夫妻共同经营 | 人工成本低，执行力强 | 家庭和店铺绑定，休息能力弱 |
| 返乡创业者 | 有城市消费经验 | 品牌审美和营销意识较好 | 容易高估本地消费力 |
| 背债加盟新手 | 部分资金来自贷款 | 决心强，短期行动快 | 利息压力大，容错率最低 |

### 3.2 开局心理事件

进入游戏前给玩家一个“入局诱因”，让选择不是冰冷参数：

- 被裁后刷到“夫妻奶茶店月入十万”的视频。
- 朋友说县城汉堡店比上班强。
- 加盟招商经理承诺总部扶持。
- 商场空铺招商，前三个月房租优惠。
- 家里希望你别再漂着，做点自己的事。

这些诱因会在后续反复出现，形成心理压力线。

## 4. 两种玩法流程

## 4.1 快速体验版

快速体验版继承现有 7 天挑战，但改成“四件套”主题。

### 4.1.1 流程

1. 选择角色：被裁中层、县城夫妻店、返乡创业者。
2. 选择赛道：奶茶、汉堡、咖啡、烘焙。
3. 选择开局包：保守、自营、加盟、重装修。
4. 进入 7 天经营。
5. 每天做 2-3 个关键决策。
6. 晚上看账本。
7. 第 7 天生成结局报告。

### 4.1.2 每天结构

每天分 4 段：

| 阶段 | 用户行为 | 系统反馈 |
| --- | --- | --- |
| 早晨备战 | 备货、排班、定价、是否投流 | 影响成本、客流、出错率 |
| 白天营业 | 处理订单、活动、突发问题 | 展示流水、排队、差评、损耗 |
| 晚上算账 | 查看损益表 | 拆解净现金流 |
| 家庭压力 | 处理家庭/贷款/身体事件 | 影响现金、压力、体力 |

### 4.1.3 适合保留的现有能力

现有项目已经有这些能力，可以继续用：

- 每天精力点。
- 经营动作卡。
- 每日事件。
- 渠道看板。
- 营业过程反馈。
- 第 7 天经营周报。
- 排行榜和转化记录。

需要替换的内容：

- 店型从“汉堡、奶茶咖啡、小电商”改成“四件套”。
- 指标从“经营周报导向”改成“现金流与返贫风险导向”。
- 结局从“经营评分”改成“创业体检报告”。

## 4.2 完整流程版

完整流程版是主体验，不再以 7 天为完整周期，而是模拟一个小店从动心到经营 6 个月左右的压缩流程。

### 4.2.1 总体章节

| 章节 | 阶段名称 | 模拟周期 | 核心问题 |
| --- | --- | --- | --- |
| 0 | 动心 | 1 个夜晚 | 你为什么想开店？ |
| 1 | 入局评估 | 1-3 天 | 你真的算过账吗？ |
| 2 | 选赛道 | 1 周 | 四件套哪条路最适合你？ |
| 3 | 筹备开店 | 2-4 周 | 钱花在哪里？合同怎么签？ |
| 4 | 开业冲刺 | 7 天 | 流水起来了，利润呢？ |
| 5 | 稳定经营 | 4-8 周 | 复购、成本、人员开始决定生死 |
| 6 | 危机与诱惑 | 1-2 个月 | 追加投入、贷款、转让、扩张怎么选？ |
| 7 | 结局复盘 | 结算 | 继续、调整、止损、返贫或跑通 |

### 4.2.2 章节 0：动心

目标：建立人物动机，让玩家知道自己不是在玩抽象店铺，而是在拿家庭现金流冒险。

页面内容：

- 当前年龄、家庭结构、房贷或租房压力。
- 银行卡余额、可动用积蓄、可借款额度。
- 最近一次情绪触发：裁员、收入下降、看到成功案例、朋友推荐。
- 系统问题：“你要不要认真做一次开店测算？”

关键设计：

- 玩家可以选择“不创业，先找工作/副业验证”，这不是失败，而是一个早期止损结局。
- 继续开店会进入入局评估。

### 4.2.3 章节 1：入局评估

目标：让玩家第一次看到“开店不是开门就有钱”。

决策项：

- 是否做市场调研。
- 是否蹲点数客流。
- 是否询问真实店主。
- 是否看加盟合同。
- 是否做家庭现金流底线。

核心指标：

- 信息完整度。
- 冲动指数。
- 家庭安全垫。
- 可承受亏损月数。

失败风险：

- 不调研直接签约，会在后面埋下高房租、高加盟费、客群错配等隐患。
- 过度乐观会导致预算不足。

### 4.2.4 章节 2：选赛道

目标：四件套不只是皮肤，而是四套不同的风险模型。

#### 奶茶

优势：

- 标准化强，上手快。
- 年轻客群明确。
- 爆品和活动容易带来短期流量。

风险：

- 同质化最严重。
- 平台满减和低价竞品频繁。
- 水果、奶制品、茶底损耗明显。
- 高峰依赖员工熟练度。

核心玩法：

- SKU 控制。
- 爆品测试。
- 备货预测。
- 学校/商圈节奏。

#### 汉堡

优势：

- 正餐属性强，外卖需求稳定。
- 套餐客单相对可控。
- 出餐标准化程度高。

风险：

- 油炸设备和食品安全压力高。
- 外卖评价影响大。
- 午晚高峰集中，错单损失明显。
- 平台抽成与满减同时压缩利润。

核心玩法：

- 出餐效率。
- 外卖定价。
- 差评处理。
- 设备维护。

#### 咖啡

优势：

- 单杯毛利看起来高。
- 品牌感和会员复购有空间。
- 可做办公、社区、社交场景。

风险：

- 装修和位置投入高。
- 客流不稳定，坪效压力大。
- 低价连锁竞争强。
- 氛围投入不一定转化为订单。

核心玩法：

- 选址与租金。
- 会员复购。
- 客单与翻台。
- 产品线克制。

#### 烘焙

优势：

- 产品展示强，节日爆发明显。
- 可做预售、团购、社区团。
- 客单有提升空间。

风险：

- 报废率是核心杀手。
- 师傅人工贵。
- 生产节奏复杂。
- 平日冷清、节日爆单，波动大。

核心玩法：

- 产量预估。
- 报废处理。
- 预售机制。
- 节日备货。

### 4.2.5 章节 3：筹备开店

目标：让玩家体验“开业前现金先少一半”。

筹备决策：

- 加盟还是自营。
- 店铺位置：商场、学校边、写字楼、社区、景区。
- 面积大小。
- 装修档位。
- 设备档位。
- 首批物料。
- 员工数量。
- 是否请代运营或投流团队。

需要展示一张启动资金表：

| 项目 | 示例 |
| --- | --- |
| 加盟费/品牌使用费 | 30,000-120,000 |
| 保证金 | 10,000-50,000 |
| 设备 | 30,000-150,000 |
| 装修 | 40,000-200,000 |
| 房租押付 | 押二付三或押三付三 |
| 首批物料 | 10,000-50,000 |
| 开业营销 | 5,000-50,000 |
| 流动资金 | 至少覆盖 3-6 个月 |

页面反馈：

```text
可动用资金：¥220,000
已承诺支出：¥168,000
剩余流动资金：¥52,000
每日固定成本：¥1,180
不含家庭支出可撑：44 天
含家庭支出可撑：28 天
风险提示：流动资金偏薄，开业后两周若未达到预期，容易被迫借款。
```

### 4.2.6 章节 4：开业冲刺

目标：给玩家“热闹但不一定赚钱”的冲击。

周期：开业前 7 天。

核心机制：

- 开业活动能提高流水，但会降低利润。
- 投流能带来订单，但可能带来低质量客群。
- 总部会建议继续加码物料、设备或广告。
- 第一次差评会影响口碑。
- 员工熟练度不足会导致出餐慢、损耗高。

每日结算必须展示损益表：

```text
今日营业额：¥4,860
原料成本：-¥1,720
平台抽成：-¥486
满减优惠：-¥620
人工成本：-¥760
房租日摊：-¥420
水电杂费：-¥130
报废损耗：-¥210
营销投流：-¥800
今日净现金流：-¥286
```

关键反馈文案：

> 今天店里很忙，但忙不等于赚钱。亏损主要来自开业满减和投流。

### 4.2.7 章节 5：稳定经营

目标：从开业兴奋进入经营现实。

周期：4-8 周压缩为若干回合。

每回合代表一周，玩家要处理：

- 菜单是否精简。
- 是否砍掉低毛利爆品。
- 是否调整营业时间。
- 是否减少员工。
- 是否加外卖平台。
- 是否做会员储值。
- 是否坚持投流。
- 是否做周报复盘。

核心系统：

- 复购系统。
- 口碑系统。
- 库存损耗系统。
- 员工熟练度系统。
- 家庭压力系统。
- 现金流预警系统。

周结算要比日结算更强：

```text
本周流水：¥32,400
本周净现金流：¥1,260
累计现金：¥39,800
家庭固定支出后剩余：¥31,300
现金可撑周数：3.7 周
最大亏损项：平台满减 ¥3,420
最值得保留动作：会员复购带来 ¥4,860
```

### 4.2.8 章节 6：危机与诱惑

目标：模拟中年返贫真正的危险点：不是第一笔亏损，而是亏损后继续加码。

危机事件：

- 对面新开低价竞品。
- 商场取消免租优惠。
- 员工离职。
- 食材涨价。
- 外卖平台调整规则。
- 家里老人住院检查。
- 孩子学费或补课费到期。
- 贷款还款日到来。

诱惑事件：

- 加盟总部推荐升级店型。
- 招商经理说再投广告就起量。
- 朋友建议开第二家摊薄成本。
- 短视频刷到同品类成功案例。
- 房东说续签要涨租。
- 有人愿意低价接手门店。

核心选择：

| 选择 | 短期效果 | 长期风险 |
| --- | --- | --- |
| 追加投流 | 订单上升 | 利润继续变薄 |
| 借款续命 | 现金增加 | 压力和利息上升 |
| 砍 SKU | 损失部分客流 | 降低损耗 |
| 裁员/夫妻顶班 | 降人工 | 体力下降、家庭压力上升 |
| 转让止损 | 承认亏损 | 保住现金流底线 |
| 继续熬 | 保留希望 | 可能触发返贫结局 |

这一章要明确设计“止损胜利”。如果玩家在现金流恶化前转让、清库存、偿还部分债务，结局应高于盲目加码。

### 4.2.9 章节 7：结局复盘

结局不是一句话，而是一份“创业体检报告”。

报告结构：

- 你的身份与赛道。
- 启动资金使用情况。
- 经营总流水。
- 累计净现金流。
- 最大亏损来源。
- 最危险的三个决策。
- 做对的三个决策。
- 家庭现金流是否被击穿。
- 如果继续经营，预计还能撑多久。
- 系统建议：继续、调整、缩小、转让、止损。

结局类型：

| 结局 | 描述 |
| --- | --- |
| 谨慎止损 | 亏了钱，但保住了家庭底线 |
| 微利跑通 | 店铺形成小额正现金流，但仍需谨慎 |
| 虚假繁荣 | 流水好看，净现金流长期为负 |
| 借债续命 | 靠贷款维持，风险快速累积 |
| 家庭透支 | 店还在，但家庭压力爆表 |
| 返贫触发 | 现金断裂，债务和固定支出无法覆盖 |
| 稳健转型 | 小店未必成功，但玩家转向副业/打工/轻资产方案 |

## 5. 核心系统设计

### 5.1 指标体系

完整流程版建议使用 8 个一级指标。

| 指标 | 含义 |
| --- | --- |
| 现金 | 当前可支配现金 |
| 净现金流 | 每日/每周真实进出 |
| 口碑 | 影响自然客流和转化 |
| 复购 | 影响稳定收入 |
| 体力 | 影响出错率和家庭压力 |
| 家庭压力 | 影响可承受亏损和事件后果 |
| 信息完整度 | 影响玩家能否看到真实成本 |
| 冲动指数 | 影响诱惑事件的负面放大 |

### 5.2 账本模型

基础公式：

```text
客流 = 基础客流 × 位置系数 × 天气系数 × 口碑系数 × 营销系数 × 竞争系数

营业额 = 客流 × 转化率 × 客单价

毛利 = 营业额 - 原料成本 - 报废损耗 - 满减优惠

经营净现金流 = 毛利 - 人工 - 房租日摊 - 平台抽成 - 水电杂费 - 营销 - 维修

家庭后净现金流 = 经营净现金流 - 家庭固定支出 - 贷款还款
```

页面上不要只显示总分，要持续显示“还能撑多久”：

```text
现金可撑天数 = 当前现金 / 最近 7 日平均现金流缺口
```

### 5.3 品类参数

| 品类 | 客单价 | 表面毛利 | 最大风险 | 独有系统 |
| --- | ---: | ---: | --- | --- |
| 奶茶 | 低 | 中 | 价格战、损耗、竞品 | 爆品热度、天气、学生周期 |
| 汉堡 | 中 | 中 | 外卖差评、设备、出餐 | 高峰产能、设备健康 |
| 咖啡 | 中高 | 高 | 房租、坪效、复购 | 座位利用、会员习惯 |
| 烘焙 | 中 | 中高 | 报废、师傅、预估 | 产量预测、临期处理 |

### 5.4 事件系统

事件分 5 类：

1. 经营事件：客流、竞品、平台、差评、设备、库存。
2. 家庭事件：房贷、孩子、父母、伴侣、身体。
3. 加盟事件：总部培训、物料包、升级包、区域保护争议。
4. 市场事件：低价连锁、节假日、天气、商圈变化。
5. 心理事件：成功案例刺激、沉没成本、亲友评价、焦虑刷屏。

事件需要有前后因果。例如：

- 前期没看合同，后面触发“总部指定物料价格偏高”。
- 长期不整理账本，后面无法判断应该砍哪个 SKU。
- 体力长期过低，后面触发出错、争吵、身体报警。

### 5.5 决策卡结构

每张决策卡包含：

```js
{
  id: "cutLowMarginSku",
  title: "砍掉低毛利爆品",
  phase: "stable",
  cost: { cash: 0, energy: 1 },
  effect: {
    revenue: -0.08,
    margin: 0.06,
    waste: -0.12,
    rating: -1,
    information: 2
  },
  risk: ["短期客流下降", "老客不满"],
  insight: "爆品如果只带来忙碌，不带来利润，就需要重新定价或砍掉。"
}
```

### 5.6 难度系统

建议难度不是简单调高亏损，而是改变信息透明度和家庭安全垫。

| 难度 | 设计 |
| --- | --- |
| 轻松体验 | 事件较温和，给更多提示 |
| 现实模式 | 成本和事件更接近真实经营 |
| 中年高压 | 家庭固定支出高，贷款压力高 |
| 背债模式 | 初始现金看似多，但还款周期短 |

## 6. 页面与交互规划

### 6.1 页面地图

```text
首页
  ├─ 快速体验版
  │   ├─ 角色/赛道选择
  │   ├─ 7 天经营台
  │   ├─ 每日晚间账本

  └─ 完整流程版
      ├─ 角色与家庭底线
      ├─ 入局评估
      ├─ 赛道选择
      ├─ 筹备开店
      ├─ 开业冲刺
      ├─ 稳定经营
      ├─ 危机与诱惑
      └─ 创业体检报告
```

### 6.2 首页

第一屏不做营销长页，直接给选择：

- 标题：中年返贫四件套：小店生死账
- 两个主按钮：完整流程、快速体验
- 四个赛道入口：奶茶、汉堡、咖啡、烘焙
- 最近一次挑战继续入口

首页文案建议：

> 你以为是在开一家小店，其实是在管理现金流、家庭压力和沉没成本。

### 6.3 经营台

布局建议：

- 左侧：现金、净现金流、可撑天数、家庭压力、体力。
- 中间：门店场景、订单流、事件反馈。
- 右侧：今日/本周决策卡。
- 底部：账本摘要和风险提示。

所有模式都要突出“账本”：

- 当日流水。
- 当日利润。
- 当日净现金流。
- 累计投入。
- 剩余现金。
- 可撑天数。

### 6.4 账本页

账本页是项目灵魂，必须比动画更重要。

展示格式：

```text
卖了很多：
营业额 +¥5,420

花得更多：
原料 -¥1,680
人工 -¥780
房租日摊 -¥560
平台抽成 -¥542
满减优惠 -¥690
营销投流 -¥900
损耗报废 -¥260

最后剩下：
今日净现金流 +¥8
家庭后净现金流 -¥292
```

系统解读：

> 今日没有输在产品，而是输在满减和投流。你需要判断这些订单是否会复购，否则只是花钱买热闹。

### 6.5 结局页

结局页应支持分享，但不能只做“分数”。

分享文案模板：

```text
我在《中年返贫四件套》里开了一家咖啡店。
6 个月模拟流水 ¥186,400，净现金流 -¥24,800。
最大亏损来源：房租和装修投入。
系统建议：停止追加投入，优先转让止损。
```

## 7. 内容资产规划

### 7.1 文案语气

保持冷静、现实、有一点网络梗，但不要油腻。

可用风格：

- “流水很好看，现金流很难看。”
- “今天店里很忙，但账上没留下钱。”
- “这不是你不努力，是成本结构不允许你靠忙解决问题。”
- “止损不是认输，是把家庭现金流从火线上撤下来。”

避免：

- “你真菜。”
- “中年人活该。”
- “创业必死。”
- “稳赚不赔。”

### 7.2 事件卡示例

```text
事件：招商经理的电话
内容：对方说首月流水不够，是因为你没有买本地达人套餐。
选择 A：追加 ¥8,000 投流
选择 B：先看复购数据
选择 C：暂停活动，调整菜单
```

```text
事件：晚上 11 点的账本
内容：今天营业额破纪录，但你发现净现金流只有 ¥46。
选择 A：继续满减冲榜
选择 B：下调优惠力度
选择 C：做会员复购测试
```

```text
事件：伴侣的提醒
内容：家里下个月有房贷、学费和老人检查费，对方希望你给一个止损线。
选择 A：承诺不再追加
选择 B：再撑一个月
选择 C：借钱做最后一波活动
```

### 7.3 现实解释卡

每个关键系统都可以配一个小解释，帮助用户理解：

- 什么是净现金流。
- 为什么流水不等于利润。
- 为什么报废会杀死烘焙店。
- 为什么咖啡店怕低坪效。
- 为什么奶茶店容易陷入价格战。
- 为什么外卖满减会吞掉汉堡店利润。

## 8. 技术改造建议

### 8.1 当前项目改造路径

现有 `public/game.js` 是单文件逻辑，适合先做快速版重构；完整流程版建议逐步模块化。

建议结构：

```text
public/
  index.html
  styles.css
  game.js
  data/
    roles.js
    business-types.js
    events.js
    decisions.js
    endings.js
  engine/
    simulation.js
    ledger.js
    risk.js
    report.js
```

如果继续保持无构建工具，也可以用普通 script 分文件；如果后续升级复杂度，建议再引入 Vite。

### 8.2 数据模型

推荐核心状态：

```js
const state = {
  mode: "full",
  phase: "precheck",
  day: 1,
  week: 1,
  roleId: "laidOffManager",
  businessId: "coffee",
  locationId: "office",
  cash: 220000,
  debt: 0,
  familyPressure: 35,
  energy: 80,
  reputation: 50,
  repeatRate: 0.12,
  information: 20,
  impulse: 55,
  ledger: [],
  decisions: [],
  flags: {}
};
```

### 8.3 计算模块

拆成四个函数：

```js
simulateTraffic(state, decisions, event)
calculateLedger(state, traffic, decisions, event)
applyFamilyPressure(state, event)
analyzeResult(state)
```

这样快速版和完整流程版可以共用引擎，只是周期不同。

### 8.4 存档

完整流程版需要本地保存：

- 当前章节。
- 当前现金与债务。
- 已做决策。
- 已触发事件。
- 账本记录。
- 结局报告。

第一版可用 `localStorage`，后续再接后端记录。

## 9. 迭代路线

### 9.1 第一阶段：快速体验版主题替换

目标：让现有 7 天挑战变成“返贫四件套”。

任务：

- 替换店型为奶茶、汉堡、咖啡、烘焙。
- 增加角色选择。
- 增加家庭压力和可撑天数。
- 重写事件池为餐饮创业事件。
- 重写结局报告。

### 9.2 第二阶段：完整流程版骨架

目标：建立章节式完整体验。

任务：

- 首页增加“完整流程/快速体验”双入口。
- 增加章节状态机。
- 做角色与家庭底线页。
- 做入局评估页。
- 做筹备开店页。
- 做周结算账本。

### 9.3 第三阶段：危机与止损系统

目标：让体验从经营游戏变成风险模拟。

任务：

- 增加债务、家庭、体力长期影响。
- 增加追加投入和止损决策。
- 增加结局体检报告。
- 增加分享图或分享文案。

### 9.4 第四阶段：商业闭环融合

目标：和现有 `money-lab` 产品形成闭环。

任务：

- 结局页引导用户使用真实经营周报生成器。
- 增加“我的小店风险测算表”下载或页面。
- 生成可复用的经营复盘模板。
- 引导真实小店老板提交需求，但避免收集敏感信息。

## 10. MVP 验收标准

快速体验版完成标准：

- 用户能选择四件套任一品类。
- 用户能选择至少 3 个角色。
- 单局能在 10 分钟内完成。
- 每天都有经营决策、营业反馈、账本结算。
- 结局能指出最大亏损来源和止损建议。

完整流程版完成标准：

- 用户能完整走完动心、评估、选赛道、筹备、开业、稳定经营、危机、结局。
- 系统能持续展示现金、债务、家庭压力、可撑天数。
- 至少 30 张经营事件卡、15 张家庭/心理事件卡、20 张决策卡。
- 至少 7 种结局。
- 中途可保存并继续。

## 11. 下一步建议

建议下一步先做“快速体验版主题替换”，因为它能最大限度复用现有代码，并尽快验证用户是否喜欢这个题材。随后再把完整流程版做成章节状态机，逐步迁移已有计算逻辑。

第一批实现优先级：

1. 确定四件套参数表。
2. 改造开局选择和角色系统。
3. 新增现金流账本。
4. 增加家庭压力与可撑天数。
5. 重写结局报告。
6. 再扩展完整流程版章节。
